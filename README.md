# Конструктор форм · LinkForms

Автор: **gbroccoli**. Компонент Joomla 3.10 / PHP 7.4 для анкет по ссылке и QR, ответов и Excel. Текущая версия указана в `com_linkforms/linkforms.xml`.

## Автоматическая сборка

После загрузки содержимого этой папки в GitHub откройте **Actions → Build Joomla component**. Workflow запускается при push, pull request и вручную через **Run workflow**. Он проверяет синтаксис PHP 7.4 в Docker, документацию, собирает установочный ZIP, проверяет его структуру и создаёт контрольную сумму.

После успешного запуска откройте его страницу и раздел **Artifacts → linkforms-install-номер**. Скачайте и распакуйте артефакт: внутри находятся `com_linkforms.zip` и `SHA256SUMS.txt`. В Joomla загружайте именно внутренний `com_linkforms.zip`, а не ZIP артефакта GitHub. Артефакт хранится 30 дней; workflow можно запустить повторно. GitHub Actions должны быть разрешены в настройках репозитория. Секреты и доступ к рабочему сайту для сборки не нужны.

Полные SQL/HTTP-тесты требуют Joomla и отдельного окружения и автоматически здесь не запускаются. Сайт автоматически не обновляется.

## Релизы и скачивание установщика

После отправки тега **v0.20.2** workflow проверит сборку и автоматически создаст опубликованный **GitHub Release** с двумя файлами: `com_linkforms.zip` и `SHA256SUMS.txt`. Имя тега должно точно соответствовать версии манифеста (`v` + версия в `com_linkforms/linkforms.xml`). Если версии различаются, публикация остановится. Для следующей версии обновите манифест/README, отправьте изменения, затем создайте новый тег. Теги с суффиксом, например `v0.21.0-rc.1`, при соответствующей версии манифеста создают prerelease.

Пример первого релиза, после загрузки репозитория:

```sh
git tag -a v0.20.2 -m "Release 0.20.2"
git push origin v0.20.2
```

После зелёной сборки откройте **Releases → нужная версия → Assets → com_linkforms.zip**. Это прямой установщик для Joomla. Автоматически предлагаемые GitHub файлы **Source code (zip/tar.gz)** для установки не подходят. Публичные пользователи смогут скачивать релизы без входа, если сам репозиторий публичный; у частного репозитория доступ ограничен его участниками.

Прямая ссылка на текущий стабильный установщик после публикации релиза:

```text
https://github.com/YOUR-ACCOUNT/YOUR-REPOSITORY/releases/latest/download/com_linkforms.zip
```

Для конкретной версии: `https://github.com/YOUR-ACCOUNT/YOUR-REPOSITORY/releases/download/v0.20.2/com_linkforms.zip`. Замените владельца и репозиторий своими. Обычный push ветки, pull request и ручная сборка не публикуют релиз. Повторный запуск для уже опубликованного релиза не перезаписывает его файлы; незавершённый черновик может быть допубликован.

Используется встроенный `GITHUB_TOKEN`: право `contents: write` есть только у отдельной задачи публикации после успешной сборки, для PR публикация отключена. Личный токен добавлять не нужно. Если правила организации запрещают запись workflow, их должен разрешить владелец. До загрузки репозитория ни Actions, ни Releases на GitHub не запускаются.

Проверка подготовки релиза локально, без публикации:

```sh
python tools/release.py --tag v0.20.2
```

Сначала выполните локальную сборку и проверку ZIP, как описано ниже. Флаг `--publish` предназначен для workflow и действительно публикует релиз; для локальной проверки его не указывайте.

## Загрузка в свой репозиторий

Создайте пустой репозиторий на GitHub. Публикуйте содержимое **этой папки**, включая `.github/`, а не корень рабочего сайта Joomla. Например, из этой папки:

```sh
git init -b main
git add .
git commit -m "Prepare LinkForms source and automatic build"
git remote add origin https://github.com/YOUR-ACCOUNT/YOUR-REPOSITORY.git
git push -u origin main
```

Замените адрес своим. Папка подготовлена локально; эти команды ещё не выполнялись. Авторизуйтесь своим аккаунтом обычным способом, не записывайте токены в файлы.

## Локальная сборка

Нужен Python 3.9 или новее, без дополнительных пакетов:

```sh
python tools/build.py --output dist/com_linkforms.zip
python tools/verify_package.py dist/com_linkforms.zip
```

Установите ZIP поверх существующего компонента штатным установщиком Joomla. Это сохраняет формы и ответы; удалять расширение перед обновлением не нужно. Данных сайта, configuration.php, паролей и ответов в репозитории нет.
